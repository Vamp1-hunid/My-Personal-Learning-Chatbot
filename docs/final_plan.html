    Deliverable: one self-reproducible RAG chatbot package that satisfies every rule of the 130-Group Collaborative Transformer Chatbot Project assignment standards on your exact HP Pavilion hardware.     What is new in v2 (merged from chatbot1.html + chatbot2.html without diluting standards):
    • Exact downloads table (§7): every URL, installer name, size estimate, and where to unzip it. Includes the AVX vs AVX2 llama.cpp rule and the what-to-do-if-the-prebuilt-zip-fails escape hatch.

    • py -3.11 side-by-side Python loader added in case your machine already has a different Python.
    • Doctor gained 3 new checks: GPU name via CIM, llama.cpp AVX illegal-instruction smoke test (exit code 0xC000001D), and RAM based Tier-0 / Tier-1 hint.
    • Full git workflow is now in this document (§8), including .gitignore, remote, branch, pull-request and secrets-scan commands. Every repo step is copy-paste ready.
    • Streamlit UI is provided but optional and memory-safe (CLI remains primary to keep RAM low during evaluation).
    What is deliberately left out of v2 to keep the file manageable: full OCR Python code (extracts only commands, not a script), a Streamlit UI beyond ~30 lines, full 30–50 question set (template + first 6 entries here, rest in project/evaluation/questions.template.json on disk).

    One-sentence pitch: build a book-grounded retrieval system that is guaranteed to run on this laptop, then fall back gracefully when hardware is tight, and prove quality with tests, held-out evaluation and honest numbers.

    3. Hardware interpretation and design rules

    1. Weak CPU is the bottleneck, not RAM. The best local path is a 0.5B–1.5B quantized model at 2 threads. Never make 3B+ the required path; that was the earlier draft’s mistake (it treated 3B as Tier-0).
    2. RAM is good, still not generous. 10.9 GB usable; target 4–6 GB; warn at 6 GB; hard-stop at 7 GB. Integrated graphics memory is not free extra room.
    3. HDD changes priorities, not possibilities. Sequential reads win. Use JSONL, cache fulltext/*.jsonl, embeddings.npy, book.faiss, and the OCR cache. Never re-scan PDFs during a demo; never read passages.jsonl line-by-line in the hot loop — load it once, keep in RAM.
    4. Embedding + retrieval are feasible; generation is not trivial.
      • Embedding all-MiniLM-L6-v2 is ~0.5 GB RSS and fast enough for a 15-book corpus in one sitting.
      • faiss-cpu IndexFlatIP is exact, tiny, safe. This is the assignment-standard “local vector index”.
      • Tiny local generation is the right target: 0.5B–1.5B Q4_K_M. Bigger is Tier-2/only-if-new-hardware, never required.
    5. Deterministic answers. temperature 0, near-zero top_p, stop sequence, short maximum_new_tokens, exact context cap. Two runs produce the same answer. Human review can then be done reliably.
    6. Abstention is not optional. Low retrieval score, a refusal marker in the model’s own text, or no valid surviving citation → insufficient_evidence: true. The falsification of a non-retrieved citation is dropped before it gets shown.
    7. Conflicts are surfaced, not averaged. When retrieved passages disagree (CONFLICT: prefix from the model, or negation-based heuristic, or post-hoc human flag) the objective truth is not silently picked; the payload adds a conflicts array and the answer text itself starts with that prefix so the 3-key contract stays intact.

    Offline (once, or after a model/config change):
  data/books/*.pdf
      │  ingest.py ──> data/cache/pages/{book_id}.jsonl     (page-level raw text, cached)
      │  chunk.py  ──> data/passages/passages.jsonl         (160w/30o, per page, schema-valid)

Online (per question):
  question ──> retrieve(question, top_k) ──> top-k passages + score, book_id, page, chunk_id, edition
      │
      ├─ if top score < threshold_score (0.30) ──> ABSTAIN (insufficient_evidence: true)
      │
      ├─否则 generation: llama.cpp llama-server (separate CPU process, temp 0, max_new_tokens 96)
      │     ├─ fallback 1: Ollama CPU mode (documented alt)
      │     ├─ fallback 2: approved hosted API (guarded by approval_reference)
      │     └─ fallback 3: extractive, answer text explicitly labelled
      │
      ├─ citations.validate: keep only chunk IDs present in BOTH the retrieved set
      │                      AND the stored passages (exact book_id + page match)
      ├─ if zero sources survive ──> ABSTAIN
      │
      └─ validate_answer (3 keys, sources valid, page match) ──> return JSON
            {"answer": "...", "sources": [...], "insufficient_evidence": false}

Usage:

"""
from __future__ import annotations

import importlib
import json
import os
import platform
import shutil
import subprocess
import sys

ROOT = Path(__file__).resolve().parent.parent
SUPPORTED_PY = [(3, 10), (3, 11), (3, 12)]
RECOMMENDED_PY = (3, 11)
PACKAGES = ["fitz", "sentence_transformers", "faiss", "numpy", "yaml",
            "psutil", "pytest", "streamlit"]
LIMAVX_AVX2_HINT = ("The AMD A8-7410 uses Puma+ cores; they support AVX but usually NOT AVX2. "
                    "A llama.cpp build that requires AVX2 will die with 'illegal instruction' "
                    "(Windows exit code 3221225501 = 0xC000001D).")


def memory_profile():
    try:
        import psutil
        vm = psutil.virtual_memory()
        return vm.total, vm.available
    except Exception:
        class MEMORYSTATUSEX(ctypes.Structure):
            _fields_ = [("dwLength", ctypes.c_ulong), ("dwMemoryLoad", ctypes.c_ulong),
                        ("ullTotalPhys", ctypes.c_ulonglong), ("ullAvailPhys", ctypes.c_ulonglong),
                        ("ullTotalPageFile", ctypes.c_ulonglong), ("ullAvailPageFile", ctypes.c_ulonglong),
                        ("ullTotalVirtual", ctypes.c_ulonglong), ("ullAvailVirtual", ctypes.c_ulonglong),
                        ("ullAvailExtendedVirtual", ctypes.c_ulonglong)]
        stat = MEMORYSTATUSEX()
        stat.dwLength = ctypes.sizeof(MEMORYSTATUSEX)
        ctypes.windll.kernel32.GlobalMemoryStatusEx(ctypes.byref(stat))
        return stat.ullTotalPhys, stat.ullAvailPhys


def detect_gpu_name() -> str:
    try:
        out = subprocess.run(["powershell", "-NoProfile", "-Command",
                              "(Get-CimInstance Win32_VideoController).Name"],
                             capture_output=True, text=True, timeout=10)
        return (out.stdout or "").strip() or "unknown"
    except Exception as exc:
        return f"unknown ({type(exc).__name__})"


def check_llama_binary(exe_path: Path) -> str:
    """Smoke test: 0xC000001D (3221225501) on Windows means illegal instruction."""
    if not exe_path.is_file():
        return f"skipped (no file at {exe_path})"
    try:
        r = subprocess.run([str(exe_path), "--version"], capture_output=True,
                           text=True, timeout=20)
        if r.returncode == 0:
            return f"OK   exit={r.returncode}"
        if r.returncode == 3221225501:
            return ("FAIL  illegal instruction (0xC000001D) - needs AVX2, find an -avx build "
                    "from an earlier llama.cpp release instead")
        return f"FAIL  exit={r.returncode} stderr={r.stderr[:200]}"
    except Exception as exc:
        return f"FAIL  {type(exc).__name__}: {exc}"


def main(json_out: bool = False):
    total, avail = memory_profile()
    total_gb, avail_gb = ((total or 0) / 2**30, (avail or 0) / 2**30)
    py = sys.version_info[:3]
    found, missing = check_packages()
    gpu = detect_gpu_name()
    llama = check_llama_binary(ROOT / "tools" / "llama.cpp" / "llama-server.exe")
    free_disk_gb = shutil.disk_usage(str(ROOT)).free / 2**30
    report = {
        "os": platform.platform(), "machine": platform.machine(),
        "python": f"{py[0]}.{py[1]}.{py[2]}",
        "python_supported": py[:2] in SUPPORTED_PY,
        "logical_cores": os.cpu_count(),
        "suggested_threads": 2,
        "ram_total_gb": round(total_gb, 2),
        "ram_available_gb": round(avail_gb, 2),
        "gpu": gpu,
        "gpu_note": ("NVIDIA present but plan is CPU-first" if "NVIDIA" in gpu.upper()
                     else "no NVIDIA: CPU-only (integrated GPU is not AI VRAM)"),
        "free_disk_gb": round(free_disk_gb, 2),
        "packages_found": found, "packages_missing": missing,
        "llama_cpp_smoke_test": llama, "avx_note": LIMAVX_AVX2_HINT,
        "suggested_tier": 0 if avail_gb < 6.0 else 0,
        "suggested_memory_budget_gb": round(min(6.0, max(2.0, avail_gb - 3.0)), 1),
        "hard_cap_gb": 7.0,
        "problem_count": len(missing) + (0 if py[:2] in SUPPORTED_PY else 1),
    }
    if json_out:
        out = ROOT / "doctor_report.json"
        out.write_text(json.dumps(report, indent=2), encoding="utf-8")
        print(f"doctor_report.json written -> {out}")
    for k, v in report.items():
        print(f"{k}: {v}")
    return report


def check_packages():
    found, missing = [], []
    for pkg in PACKAGES:
        try:
            importlib.import_module(pkg)
            found.append(pkg)
        except Exception:
            missing.append(pkg)
    return found, missing


if __name__ == "__main__":
    main("--json" in sys.argv)
    sys.exit(0)

    """Extracts PDFs page by page; caches pages JSONL; flags books as 'needs OCR'"""
import json
import pymupdf
from pathlib import Path
from util import ROOT, log, write_jsonl, read_jsonl

SCAN_MIN_CHARS = 50
SCAN_RATIO = 0.5
MANIFEST = ROOT / "data" / "book_manifest.json"
BOOKS_DIR = ROOT / "data" / "books"
PAGE_CACHE = ROOT / "data" / "cache" / "pages"

def extract_book(pdf: Path) -> list[dict]:
    """Page-level raw text for one PDF, cached for later chunking."""
    with pymupdf.open(pdf) as doc:
        pages = []
        for i, page in enumerate(doc, start=1):
            text = page.get_text("text").replace("\x00", " ")
            pages.append({"page": i, "text": text, "char_count": len(text.strip())})
        return pages

def main() -> None:
    books = json.loads(MANIFEST.read_text(encoding="utf-8"))
    PAGE_CACHE.mkdir(parents=True, exist_ok=True)
    for book in books:
        cache = PAGE_CACHE / f"{book['book_id']}.jsonl"
        if not cache.is_file():
            pdf = BOOKS_DIR / book["filename"]
            if not pdf.is_file():
                log.error("missing PDF: %s", pdf)
                book["processing_status"] = "failed"
                continue
            try:
                write_jsonl(cache, extract_book(pdf))
            except Exception as exc:
                log.error("FAILED %s: %s", pdf, exc)
                book["processing_status"] = "failed"
                continue
        pages = read_jsonl(cache)
        empty = sum(1 for p in pages if p["char_count"] < SCAN_MIN_CHARS)
        book["processing_status"] = ("needs OCR" if pages and empty / len(pages) > SCAN_RATIO
                                     else "processed")
        log.info("%s: %d pages, %d empty, status=%s",
                 book["book_id"], len(pages), empty, book["processing_status"])
    MANIFEST.write_text(json.dumps(books, indent=2, ensure_ascii=False), encoding="utf-8")

if __name__ == "__main__":
    main()
    Cache rule: rerunning ingest.py after a crash is cheap; it only re-extracts a book whose page cache is missing. Do not add a second cache format.

    17. OCR plan (uB-Mannheim Tesseract + ocrmypdf, cached once)

    1. Run python src\ingest.py; it flags books whose page cache is mostly empty. For those books set processing_status == "needs OCR".
    2. Install Tesseract (UB-Mannheim 64-bit) into a per-user folder and add that folder to PATH; install ocrmypdf with pip install ocrmypdf.
    3. OCR one book at a time, writing the fixed PDF to data\cache\ocr\<book_id>.pdf and then rerun :python:ingest.py on the OCR’d file. 
      ocrmypdf --skip-text --jobs 1 --output-type pdfine input.pdf out.pdf
      The --jobs 1 and --skip-text flags together avoid re-OCR for already-processed books and give the HDD time to breathe.
    4. OCR output is cached. Never re-OCR a book whose data\cache\ocr\<book_id>.pdf already exists. After the OCR is done, re-run python src\ingest.py to refresh the page cache.
    5. Inspect tables, equations and page numbers by hand; mark artifacts with needs_review: true rather than deleting, so failures stay visible for human review.
    6. Run on a book that failed extraction? Record it in the manifest with processing_status = "failed" and, if you want to drop it, a corroborating permission_status note (e.g. "corrupted PDF").
    OCR is not a required stage: most textbooks are already text PDFs. Use it only on books the ingest flags needs OCR. Do not OCR the whole batch if a scan is ambiguous — use approved exception status instead and record why.

    18. Chunking — src/chunk.py

    """Turns cached page text into schema-valid passages.jsonl"""
import re, json
from util import ROOT, cfg, read_jsonl, write_jsonl, log

GROUP_ID = cfg("models")["group_id"]
CH = cfg("chunking")

def clean_text(t: str) -> str:
    t = t.replace("\u00ad", "")                     # soft hyphens
    t = re.sub(r"-\n(\w)", r"\1", t)                 # join words split across lines
    t = re.sub(r"[ \t]+", " ", t)
    return re.sub(r"\n{3,}", "\n\n", t).strip()

def split_words(text: str, size: int, overlap: int) -> list[str]:
    w, out, s = text.split(), [], 0
    while s < len(w) and w:
        piece = " ".join(w[s:s + size])
        if piece: out.append(piece)
        if s + size >= len(w): break
        s = max(s + 1, s + size - overlap)           # guarantee forward motion
    return out

def main() -> None:
    manifest = {b["book_id"]: b for b in json.loads(
        (ROOT / "data" / "book_manifest.json").read_text(encoding="utf-8"))}
    rows = []
    for book_id, book in manifest.items():
        if book["processing_status"] not in ("processed", "approved exception"):
            continue
        for pg in read_jsonl(ROOT / "data" / "cache" / "pages" / f"{book_id}.jsonl"):
            t = clean_text(pg["text"])
            if len(t) < CH["min_chars"]:
                continue
            for i, piece in enumerate(split_words(t, CH["chunk_words"],
                                                  CH["overlap_words"]), start=1):
                rows.append({
                    "group_id": GROUP_ID,
                    "subject": book["subject"],
                    "book_id": book_id,
                    "title": book["title"],
                    "edition": book.get("edition", ""),
                    "author": book.get("author", ""),
                    "publisher": book.get("publisher", ""),
                    "year": book.get("year"),
                    "page": pg["page"],
                    "chunk_id": f"{book_id}_P{pg['page']}_C{i:02d}",
                    "text": piece,
                    "lang": "en",
                    "extraction_method": "pymupdf-text",
                    "needs_review": False,
                })
    write_jsonl(ROOT / "data" / "passages" / "passages.jsonl", rows)
    log.info("chunks written: %d", len(rows))

if __name__ == "__main__":
    main()

    Why 160 words / 30 overlap

    all-MiniLM-L6-v2 truncates at 256 tokens internally, and English prose runs roughly 1.3 tokens per word including punctuation and synthetic tokens. 160 words ≈ 200–210 tokens, a safety margin of ~50. 30-word overlap keeps a sentence that straddles a window boundary intact in at least one chunk while keeping chunk counts modest for your HDD.

    21. Retrieval — src/retrieve.py (the exact integration interface)

    """Required interface (do not rename the function or change its signature)"""
import numpy as np, faiss
from sentence_transformers import SentenceTransformer
from util import ROOT, cfg, read_jsonl

_S: dict = {}

def _load() -> dict:
    if not _S:
        cfgEv = cfg("models")["embedding"]
        rev = None if "PIN" in cfgEv["revision"] else cfgEv["revision"]
        _S["model"] = SentenceTransformer(cfgEv["model"], revision=rev, device="cpu")
        faiss.omp_set_num_threads(cfg("hardware")["threads_faiss"])
        _S["index"] = faiss.read_index(str(ROOT / "artifacts" / "book.faiss"))
        _S["rows"] = read_jsonl(ROOT / "data" / "passages" / "passages.jsonl")
        if _S["index"].ntotal != len(_S["rows"]):
            raise RuntimeError("index and passages are out of sync: rebuild")
    return _S

def retrieve(question: str, top_k: int = 5) -> list:
    """Return passages with text, score, book_id, title, page, and chunk_id."""
    s = _load()
    q = s["model"].encode([question], convert_to_numpy=True,
                          normalize_embeddings=True).astype("float32")
    k = max(1, min(top_k, s["index"].ntotal))
    scores, ids = s["index"].search(q, k)
    out = []
    for sc, i in zip(scores[0], ids[0]):
        if int(i) < 0:
            continue
        p = s["rows"][int(i)]
        out.append({"text": p["text"], "score": float(sc), "book_id": p["book_id"],
                    "title": p["title"], "page": p["page"], "chunk_id": p["chunk_id"],
                    "edition": p.get("edition", "")})
    return out

def passage_store() -> dict:
    """Map chunk_id -> full row; used by citations.py for cross-checks"""
    if "store" not in _S:
        _S["store"] = {r["chunk_id"]: r for r in _load()["rows"]}
    return _S["store"]
    This function is the integration point for the 130-group router: the shared router will call retrieve(question, top_k) against your local index and then merge results group by group. Every extra or missing key breaks integrators.

from typing import Optional
import yaml
from src import answer_schema
from src import citations as cite
from src.retrieve import retrieve

ROOT = pathlib.Path(__file__).resolve().parent.parent

RETRIEVAL  = yaml.safe_load((ROOT / "config" / "retrieval.yaml").read_text(encoding="utf-8"))

PASSAGE_STORE_PATH = ROOT / "data" / "passages" / "passages.jsonl"
ABSTAIN = ("The provided books do not contain sufficient evidence "
           "to answer this question.")

SYSTEM_PROMPT = (
    "Answer ONLY from the numbered passages provided. Cite each claim with its passage "
    "ID in square brackets, e.g. [BOOK_ID_P_PAGE_C_NUM]. Never invent IDs, titles, "
    "pages or facts. Keep the answer to 1-3 sentences. If passages disagree, begin with "
    "'CONFLICT:' and describe both views with their IDs. If the passages do not answer "
    "the question, reply exactly: INSUFFICIENT EVIDENCE.")

def _ctx_format(hits, max_ctx=MAX_CTX_CHARS):
    parts, used = [], 0
    for h in hits:
        block = f"[{h['chunk_id']}] ({h['title']}, page {h['page']})\n{h['text']}\n"
        if used + len(block) > max_ctx and parts:
            break
        parts.append(block)
        used += len(block)
    return "\n".join(parts), len(parts)

def _format_sources(hits):
    return [{"book_id": h["book_id"], "page": h["page"], "chunk_id": h["chunk_id"]}
            for h in hits]

def _local_generate_llama_server(prompt: str) -> Optional[str]:
    """Primary: llama.cpp llama-server over a CPU-only HTTP endpoint,
    started with the exact command in config/models.yaml"""
    tier_key = f"tier{GEN_CFG.get('tier', 0)}"
    tier_cfg = GEN_CFG.get(tier_key, {})
    body = {"messages": [{"role": "system", "content": SYSTEM_PROMPT},
                         {"role": "user",   "content": prompt}],
            "temperature": GEN_CFG.get("temperature", 0),
            "max_tokens":  tier_cfg.get("max_new_tokens", 96),
            "stop":        GEN_CFG.get("stop_markers", [])}
    req = urllib.request.Request(GEN_CFG["server_url"],
                                 json.dumps(body).encode("utf-8"),
                                 {"Content-Type": "application/json"})
    try:
        with urllib.request.urlopen(req, timeout=300) as r:
            return json.load(r)["choices"][0]["message"]["content"].strip()
    except Exception:
        return None

def _hosted_generate(prompt: str) -> Optional[str]:
    """Tier 2 fallback, only if approved; requires .env"""
    from dotenv import load_dotenv
    load_dotenv(ROOT / ".env")

        client = OpenAI(api_key=key, base_url=os.getenv("HOSTED_BASE_URL") or None)
        resp = client.chat.completions.create(model=os.environ["HOSTED_MODEL"],

                                              messages=[{"role": "system", "content": SYSTEM_PROMPT},
                                                        {"role": "user",   "content": prompt}])
        return resp.choices[0].message.content
    except Exception:
        return None

def _extractive_answer(question: str, hits) -> str:
    """Honest fallback that cites, abstains, and never invents content"""
    stop = set("a an the is are was were be been to of in on for with and or as by "
               "that this it its from what which how who whom does do did".split())
    qwords = {w for w in re.findall(r"[a-zA-Z0-9]+", question.lower()) if w not in stop}
    best, best_sc = None, 0.0
    for h in hits:
        for sentence in re.split(r"(?<=[.!?])\s+", h["text"]):
            sw = set(re.findall(r"[a-zA-Z0-9]+", sentence.lower()))
            score = len(qwords & sw)
            if score > best_sc:
                best_sc, best = score, sentence.strip()
    if best and best_sc >= 2:
        return best
    return "INSUFFICIENT-EVIDENCE"

def _load_passage_store():
    path = PASSAGE_STORE_PATH
    if not path.is_file():
        return {}
    store = {}
    with path.open(encoding="utf-8") as f:
        for line in f:
            if line.strip():
                r = json.loads(line)
                store[r["chunk_id"]] = r
    return store

def build(question: str, top_k: Optional[int] = None) -> dict:
    k = top_k or TOP_K
    hits = retrieve(question, top_k=k)
    if not hits or hits[0]["score"] < MIN_SCORE:
        return {"answer": ABSTAIN, "sources": [], "insufficient_evidence": True}
    context, used = _ctx_format(hits)
    hits_used = hits[:used]
    prompt = f"Passages:\n{context}\n\nQuestion: {question}"

    generated = _local_generate_llama_server(prompt)
    mode = "local-llm"
    if generated is None:
        generated = _local_generate_ollama(prompt)
    if generated is None:
        generated = _hosted_generate(prompt)
        mode = "hosted-approved" if generated else mode
    if not generated:
        generated = _extractive_answer(question, hits_used)
        mode = "extractive"
    text = generated.strip()

    # Cheap negation heuristic; full conflict analysis needs human review
    conflicts = []
    for i in range(len(hits_used) - 1):
        a, b = hits_used[i], hits_used[i + 1]
        if answer_schema.is_contradictory(a["text"], b["text"]):
            conflicts.append(f"Passages {a['chunk_id']} and {b['chunk_id']} appear to disagree. "
                             f"A: {a['text'][:120]}...  B: {b['text'][:120]}....")

    if "INSUFFICIENT EVIDENCE" in text.upper():
        payload = {"answer": ABSTAIN, "sources": [], "insufficient_evidence": True, "mode": mode}
        if conflicts:
            payload["conflicts"] = conflicts
        return payload

    store = _load_passage_store()
    sources = cite.validate_citations(text, hits_used, store)
    if not sources:
        generated = _extractive_answer(question, hits_used)
        if generated == "INSUFFICIENT-EVIDENCE":
            return {"answer": ABSTAIN, "sources": [], "insufficient_evidence": True,
                    "mode": "extractive"}
        sources = cite.validate_citations(generated, hits_used, store) or \
                  _format_sources(hits_used[:1])

    payload = {"answer": text, "sources": sources,
               "insufficient_evidence": False, "mode": mode}
    if conflicts:
        payload["conflicts"] = conflicts
    return payload

def answer(question: str) -> dict:
    """Public API used by CLI and Streamlit; validates the payload shape"""
    payload = build(question)
    errs = answer_schema.validate_answer(payload)
    if errs:
        return {"answer": "System error during answer validation: "
                          + "; ".join(errs) + ". Please retry.",

    24. Citation validation — src/citations.py

    """citations.py — keep only chunk IDs that exist in the store AND were retrieved"""
import json, re
from pathlib import Path

CITE = re.compile(r"\[([A-Za-z0-9_]+_P\d+_C\d{2,3})\]")

def extract_ids(answer_text: str) -> list[str]:
    seen, out = set(), []
    for cid in CITE.findall(answer_text):
        if cid not in seen:
            seen.add(cid); out.append(cid)
    return out

def validate_citations(answer_text: str, retrieved: list[dict],
                       store: dict[str, dict]) -> list[dict]:
    """A source survives only if (1) its chunk_id was retrieved this turn,
    (2) it exists in the stored passages, and (3) book_id + page match.
    Everything else is silently dropped before display."""
    retrieved_ids = {h["chunk_id"] for h in retrieved}
    sources, seen = [], set()
    for cid in extract_ids(answer_text):
        if cid in seen or cid not in retrieved_ids or cid not in store:
            continue
        seen.add(cid)
        rec = store[cid]
        hit = next(h for h in retrieved if h["chunk_id"] == cid)
        if rec["book_id"] != hit["book_id"] or rec["page"] != hit["page"]:
            continue
        sources.append({"book_id": rec["book_id"], "page": rec["page"],
                        "chunk_id": cid})
    return sources

def load_passage_store(path: str | Path) -> dict[str, dict]:
    p = Path(path); store = {}
    with p.open(encoding="utf-8") as f:
        for line in f:
            if line.strip():
                r = json.loads(line)
                store[r["chunk_id"]] = r
    return store

    25. Abstention logic

    Abstention triggers (any one):

    1. Low retrieval score. Top hit cosine < threshold_score (0.30, tune on validation only).
    2. Model refuses evidence. The tiny LLM answers exactly INSUFFICIENT EVIDENCE.
    3. No valid sources survive validation. The model may invent citations; the validator silently drops every fake; if none remain, the payload writes insufficient_evidence: true.
    4. Extractive fallback cannot find a strong sentence (fewer than 2 keyword matches) — returns INSUFFICIENT-EVIDENCE which becomes a refusal.

           "to answer this question.")

    26. Answer JSON validator — src/answer_schema.py

def validate_answer(payload: dict, store: dict) -> dict:
    """Raises ValueError; returns the payload unchanged when valid """
    if not isinstance(payload, dict):
        raise ValueError("payload must be a dict")
    if set(payload) != {"answer", "sources", "insufficient_evidence"}:
        raise ValueError(f"keys must be exactly 3: {sorted(payload)}")
    if not isinstance(payload["answer"], str) or not payload["answer"].strip():
        raise ValueError("'answer' must be a non-empty string")
    if not isinstance(payload["sources"], list):
        raise ValueError("'sources' must be a list")
    for s in payload["sources"]:
        if not isinstance(s, dict):
            raise ValueError("each source must be a dict")
        rec = store.get(s.get("chunk_id"))
        if rec is None:
            raise ValueError("source unresolvable " + str(s))
        if s["book_id"] != rec["book_id"] or s["page"] != rec["page"]:
            raise ValueError("source book/page mismatch " + str(s))
    if not isinstance(payload["insufficient_evidence"], bool):
        raise ValueError("'insufficient_evidence' must be a bool")
    if payload["insufficient_evidence"] and payload["sources"]:
        raise ValueError("abstention must carry no sources")
    return payload

def is_contradictory(a_text: str, b_text: str) -> bool:
    """Cheap negation heuristic; deeper conflict analysis is human work"""
    negs = ("not ", "cannot", "does not", "do not", "never", "no such", "impossible")
    a, b = a_text.lower(), b_text.lower()
    a_neg = any(n in a for n in negs); b_neg = any(n in b for n in negs)
    return a_neg != b_neg

    33. Integration requirements (130-group platform)

    48. Hardware do-not-do list (this laptop)

    • Do NOT attempt local 7B-class, 13B-class, or unquantized models.

    • Do NOT trust default thread counts; set OMP_NUM_THREADS=2 and OLLAMA_NUM_THREADS=2 if you use Ollama.
    • Do NOT use batch_size > 8 when embedding on an HDD — memory + swap can stall the whole run.
    • Do NOT keep multiple large models loaded simultaneously — unload between tiers.
    • Do NOT use a long multi-turn chat memory during a demo — that is why app.py avoids chat history.
    • Do NOT install global packages outside .venv; the doctor warns otherwise.
    • Do NOT leave browsers or other heavy apps open during a run; memwatch warns but does not rescue.
    • Do NOT fine-tune LLMs on this laptop — a CPU-only APU with DDR3 will take days per step.
    • Do NOT assume that merging LoRA adapters on this laptop works — it is a cloud-only research track.
    • Do NOT let the model respond without citations, or with citations that were not literally retrieved this turn.
